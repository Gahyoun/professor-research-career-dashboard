# 별자리·흐름·기관 변화

## 별자리에서 읽을 수 있는 것

`#/constellations`의 학교 모드는 선택한 박사 또는 학부 출신학교의 연구자를, 연구자 모드는 선택한 사람과 기관·연도가 겹치는 경력의 연구자를 보여줍니다. 분야와 관계 종류를 바꾸거나 노드·하이퍼엣지를 선택하면 관련 근거와 목록을 좁힐 수 있습니다. 목록은 현재 탐색 범위에 맞춰 페이지로 나뉩니다.

노드는 연구자 한 명입니다. 여러 구성원을 감싸는 윤곽은 하나의 하이퍼엣지를 나타냅니다. 윤곽 안에 우연히 위치한 흐린 노드는 그 집합의 구성원이 아닐 수 있으므로, 강조된 노드와 구성원 목록을 기준으로 읽습니다. 관계를 공유했다는 사실은 친분·공동연구·상호영향을 입증하지 않습니다.

| 관계 | 구성 기준 |
| --- | --- |
| 시간 | 같은 달력 연도에 박사과정 구간이 겹치는 연구자 집합 |
| 공간 | 국내는 같은 학교와 해당 학력의 같은 학과, 해외는 같은 학교 |
| 시공간 | 같은 학력 단계의 유효한 기관 단위와 연도가 모두 겹치는 집합 |
| 개인 경력의 겹침 | 박사·포닥·교수 경력에서 같은 기관 단위와 연도가 겹치는 관측 |

기관의 국가가 불명확하거나 국내 해당 학과가 없으면 그 공간적 관계를 만들지 않습니다. 현재 재직 학과나 넓은 분야명을 박사·학부 학과로 대체하지 않습니다. 확인된 학교 별칭만 정규화하며, 해소되지 않은 숫자 기관 코드도 관계 근거로 쓰지 않습니다. 국내 학과 문자열이 다르면 임의로 같은 학과로 합치지 않습니다.

확인된 실제 박사 구간이 있으면 우선 사용합니다. 그렇지 않으면 기본값은 `박사 취득연도 − 5`부터 취득연도까지입니다. 양 끝을 포함하므로 6개의 연도 구간이며, 실제 입학일을 뜻하지 않습니다. 선택적 학부 시간 집합은 사용자가 지정한 `박사 취득연도 − 10`부터 `− 8`까지의 3개 연도를 사용합니다. 항상 추정으로 표시하고 기본적으로 끄며, 기존 학력 날짜를 수정하지 않습니다. 추정 기간을 제외하면 두 종류의 추정 구간 모두 빠집니다.

논문 소속에서 추론한 학과는 별자리 화면에서는 기본 포함하고, 기관 시계열 화면에서는 기본 제외합니다. 두 화면 모두 선택을 바꿀 수 있습니다. 포함하면 같은 기관·기간의 채택된 저자 소속에서 하나의 명시적 학과만 확인된 경우를 사용하고, 근거에 추론 표시를 붙입니다. 해당 논문 소속은 실제 학위 수여 학과의 확인을 대신하지 않습니다. 원본에 학부 학과 근거가 없어 학부 학과는 비워 둡니다.

배치는 정규화 하이퍼그래프 라플라시안의 여러 초기값을 비교한 근사 임베딩에 집합 크기·구성원 겹침 보정, 연대 기준 배치, 노드 충돌 완화를 적용합니다. 최종 화면의 거리는 측정된 사회적 거리나 전역 최적해가 아닙니다. 자세한 가중치와 계산 규칙은 [하이퍼그래프 방법](HYPERGRAPH_METHOD.md)을 참고합니다.

개인 경력 비교 점수는 `공유한 서로 다른 기관 단위·연도 수 / 전체 서로 다른 기관 단위·연도 수`입니다. 중복 경력 행을 여러 번 세지 않으며, 양 끝 연도를 포함합니다. 학력·경력 단계, 겹친 연도, 추정 여부를 함께 확인해야 합니다.

## 학부→박사→현재기관 흐름

`#/flows`는 세 학교 정보가 모두 있는 연구자만 세 단계에 동일하게 포함합니다. 한 연구자는 각 단계에서 한 번, 인접한 두 단계 사이에서 각각 한 번 집계되므로 가운데 단계의 유입·유출 합이 보존됩니다. 누락으로 제외된 인원은 전체 표본과 구분합니다.

학교·리본·개별 경로를 선택하면 해당 경로의 목록을 볼 수 있습니다. 단계별 주요 학교 이외의 항목은 기타 묶음으로 모으고, 선택적으로 해외 교육기관을 지역별로 묶습니다. 국가를 모르는 학교를 해외로 간주하지 않습니다. 색은 학부 출신을 따릅니다.

여기서 **학부 모교 재직**은 학부 학교와 현재 재직학교가 같은 경우입니다. 박사 수여학교와 임용기관의 일치를 뜻하는 다른 자교 임용 정의와 구분해야 합니다. 학교 단위 이동을 요약하는 화면이므로 국내 학과까지 요구하는 별자리 관계와 집계 단위가 다릅니다. 확인된 학교 별칭을 사용하고 서로 다른 캠퍼스는 보존합니다. 해소되지 않은 기관 코드는 모교 재직 판정에서 제외합니다. 집계 CSV에는 학교·인원·모교 재직 여부만 포함하며 실명이나 연구자 ID는 넣지 않습니다.

## 기관별 시간 변화

`#/institutions`는 공개 명부에 있는 연구자의 유효한 박사·포닥·교수 경력을 연간 기관 집합으로 펼칩니다. 국내는 학교·학과, 해외는 학교가 집합의 단위입니다. 추정 기간과 추론 학과를 포함할지는 별도로 선택합니다. 연도 양 끝을 포함하고 공개 기준연도 뒤로는 확장하지 않습니다.

같은 연구자의 같은 기관 단위·연도는 한 번만 셉니다. 구성원 1명인 단위는 인원에 포함하되 하이퍼엣지 수와 크기에서는 제외합니다. 여러 단계가 동시에 기록된 사람은 총 질량 1을 단계 사이에 나누며, 단계 다양성은 세 단계에 대한 정규화 Shannon 엔트로피입니다.

그룹 구성 연속성은 [Cauteruccio et al. (2026), §4.2.1](https://link.springer.com/article/10.1007/s13278-026-01603-6)의 δNOA 수식을 계산합니다. 전년도와 해당 연도의 구성원 집합 모음을 각각 G, H라 할 때 다음과 같습니다.

```text
J(e, f) = |e ∩ f| / |e ∪ f|
δNOA(G, H) = [Σ(e∈G) max(f∈H) J(e,f) + Σ(f∈H) max(e∈G) J(f,e)] / (|G| + |H|)
```

원 논문의 REN 추출 대신 **기관별 연간 집합 모음**을 입력합니다. 구성원 2명 이상인 집합을 사용하고, 구성원이 완전히 같은 중복 집합은 이 지표에서 합칩니다. 학과명 자체보다 구성원 겹침을 비교하며 일대일 대응을 강제하지 않습니다. 어느 한쪽에 유효한 집합이 없으면 값은 미정입니다. 전체 REN 분석이나 STABILITY 사건 분류를 구현한 것은 아닙니다.

해외 학교는 보통 하나의 집합이어서 δNOA가 학교 구성원의 Jaccard와 같아집니다. 국내도 학과 구성이 거의 분할이라면 추가적인 구조 정보가 제한됩니다. 별도 구성원 Jaccard는 학교 인원 집합만 비교합니다. 예를 들어 같은 4명이 한 집합에서 두 집합으로 나뉘면 구성원 Jaccard는 1이지만 δNOA는 0.5입니다.

화면의 유입·유출은 인접 연도에 다른 유효한 기록이 있는 경우만 계산합니다. 기록이 처음 나타나거나 끊기는 경우는 관측 경계로 분리합니다. **현재 교수 명부를 소급한 경력 표본이므로 역사적 전체 인력, 실제 채용·퇴직 수, 기관 유지율을 추정한 결과가 아닙니다.** 추정 구간 자체가 연속성을 만들 수 있으며, 귀무모형 검정·인과 추론·기관 순위를 제공하지 않습니다.

## 메타데이터 갱신

기존 `public/data/dashboard.json`과 암호화 실명 번들은 보존하고, `constellation_metadata.json`과 함께 생성되는 manifest를 추가합니다. 보조 정보는 익명 ID에 맞춘 국가·학과·추론 여부·기관 정규화 근거와 경력 구간 대응만 담습니다. 실명, 원본 ID, 논문 제목·ID·DOI, 검증 원문 URL은 공개하지 않습니다.

아래 명령은 저장소 루트에서 실행합니다. `PRIVATE_BUILD_PROJECT`는 기존 비공개 빌드 프로젝트의 경로를 미리 설정한 변수입니다. 해당 프로젝트의 기존 익명화 salt와 연도별 원본 DB 경로 캐시를 사용합니다. 새 salt를 생성하지 않습니다. 필요하면 `--source-db`와 `--anon-salt`로 같은 원본과 salt를 명시합니다.

```bash
python3 backend/scripts/build_constellation_metadata.py \
  --private-project "$PRIVATE_BUILD_PROJECT" \
  --public-data public/data/dashboard.json \
  --year 2026 \
  --output public/data/constellation_metadata.json
```

연도가 바뀌면 해당 연도 공개 릴리스를 먼저 만든 뒤 `--year`도 바꿉니다. 생성기는 원본을 읽기 전용으로 열고 기존 익명 ID 집합과 연도 일치를 검사합니다. 화면은 다음 조건을 모두 만족할 때만 보조 정보를 결합합니다.

- manifest의 기준연도와 공개 JSON의 기준연도가 같다.
- 원본 공개 JSON 바이트의 SHA-256이 `public_data_sha256`과 같다.
- 보조 JSON 바이트의 SHA-256이 `metadata_sha256`과 같다.
- 익명 ID 집합과 인원 수가 같고, 각 경력 행의 순번·원래 기관·시작 및 종료 연도가 일치한다.

하나라도 맞지 않거나 보조 파일을 읽지 못하면 기존 공개 자료로 화면을 열고 보조 관계의 사용을 제한합니다. 같은 연도에 원본을 다시 만든 경우도 해시가 달라지므로 보조 파일을 함께 재생성해야 합니다. 현재 보완 범위와 누락은 생성된 manifest와 화면의 제외 집계를 기준으로 확인합니다.

## 국내 박사 학과의 2차 검증

RISS 학위논문 상세 또는 실제 학위 정보가 명시된 KISS 자료를 직접 확인한 결과는 **비공개 SQLite 검증 DB**로 분리합니다. 현재 소속이나 학술논문 저자 소속만으로 학위 학과를 확정하지 않습니다. 2026-09-08에 국내 박사 5명을 대상으로 공식 도메인 검색과 상세 접근을 시도한 제한적 파일럿에서는 확인 완료가 0명이었습니다. 접근 제한 2명, 동명이인 구분 미완료 2명, 조사 범위 안에서 일치 학위논문을 찾지 못한 경우 1명으로 기록했으며 학과를 만들어 채우지 않았습니다.

검토 기록의 전체 필드는 [검증 DB 스키마](../backend/scripts/verified_departments_schema.sql)를 따릅니다. 실제 저자·학위기관·취득연도·박사 학위·명시적 학과를 모두 확인한 행만 `verified`로 표시합니다. 그 외에는 `queued`, `access_limited`, `ambiguous_identity`, `no_matching_thesis`, `mismatch` 등 해당 상태와 확인일·출처를 기록합니다. 웹 근거 발췌는 출처별 25단어 이내로 제한합니다. 아래 변수는 저장소 밖 또는 무시되는 `.private/` 안의 비공개 파일을 가리켜야 합니다.

```bash
python3 backend/scripts/create_verified_overlay.py \
  --records-json "$DEGREE_REVIEW_JSON" \
  --output "$VERIFIED_DEPARTMENTS_DB"

python3 backend/scripts/build_constellation_metadata.py \
  --private-project "$PRIVATE_BUILD_PROJECT" \
  --public-data public/data/dashboard.json \
  --year 2026 \
  --verified-departments-db "$VERIFIED_DEPARTMENTS_DB" \
  --output public/data/constellation_metadata.json
```

검증 DB 생성기는 기존 파일 덮어쓰기를 거부하므로 새 검토본으로 감사 이력을 보존합니다. 내보내기는 `verified` 행에 한해 원본 인물과 익명 ID, 기관, 취득연도, 학위 단계, 학과, 공식 상세 URL 등의 일치를 검사하며, 잘못된 확인 행이 있으면 중단합니다. 이 형식 검사는 실제 출처를 읽는 검토를 대신하지 않습니다.

검증을 통과한 학과만 `phd_department_inferred: false`와 공개 근거 `verified_degree_record`로 반영합니다. 확인된 학과가 있어도 박사과정 날짜의 기존 추정 표시는 그대로 유지합니다. 검증 DB의 실명·원본 ID·출처 URL·발췌문과 검색 대기열은 커밋하거나 공개 파일로 복사하지 않습니다. 원본 DB는 수정하지 않습니다.

## 릴리스 확인

Node.js 22.13 이상에서 `pnpm test`, `pnpm lint`, `pnpm typecheck`, `pnpm data:test`, `pnpm build`를 모두 실행합니다. 테스트는 집합·연도·누락 및 국내 학과 규칙, 흐름 보존, 시간 지표, 익명 데이터 허용 필드, 메타데이터 대응과 검증 DB 불일치를 확인합니다. 브라우저에서는 잠금·해제·다시 잠금, 학교·연구자 전환, 관계 선택과 좁혀진 목록, 세 화면의 빈 결과와 작은 화면도 확인합니다. 공개 파일 범위는 [보안 문서](SECURITY.md)를 따릅니다.
