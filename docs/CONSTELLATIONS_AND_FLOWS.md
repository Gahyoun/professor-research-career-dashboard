# 별자리·흐름·기관 변화

## 별자리에서 읽을 수 있는 것

`#/constellations`의 학교 모드는 선택한 박사 또는 학부 출신학교의 연구자를, 연구자 모드는 선택한 사람의 학창·포닥·첫 조교수·현직 집합을 보여줍니다. 연구자 이름이나 익명 ID에는 현직 기관을 함께 표시합니다. 분야와 관계 종류를 바꾸거나 노드·하이퍼엣지를 선택하면 관련 근거와 목록을 좁힐 수 있습니다. 목록은 현재 탐색 범위에 맞춰 페이지로 나뉩니다.

노드는 연구자 한 명입니다. 매끈한 윤곽은 하나의 하이퍼엣지를 나타냅니다. 구불구불한 경계는 사용하지 않습니다. 윤곽 안에 우연히 위치한 흐린 노드는 그 집합의 구성원이 아닐 수 있으므로, 강조된 노드와 구성원 목록을 기준으로 읽습니다. 관계를 공유했다는 사실은 친분·공동연구·상호영향을 입증하지 않습니다.

| 관계 | 구성 기준 |
| --- | --- |
| 시간 | 같은 달력 연도에 박사과정 구간이 겹치는 연구자 집합 |
| 공간 | 국내외 모두 같은 학교와 해당 학력의 같은 학과 |
| 시공간 | 같은 학력 단계의 유효한 기관 단위와 연도가 모두 겹치는 집합 |

위 표는 학교 모드의 관계 기준입니다. 연구자 모드는 다음 네 단계로 구분합니다.

| 단계·색상 | 구성 기준 |
| --- | --- |
| 학창시절·주황 | 선택 연구자의 박사 재학 구간에 같은 학교+과거 학과+명부 분야의 박사과정 동료 또는 관측된 재직 교수 |
| 포닥시절·청록 | 선택 연구자의 포닥 구간과 같은 기관+명부 분야에서 기간이 겹치는 연구자 |
| 첫 조교수·보라 | 첫 조교수 임용이 직접 확인된 경우에만, 같은 학교+과거 학과+명부 분야에서 기간이 겹치는 재직 확인 교수. 기본적으로 끔 |
| 현직·파랑 | 공개 기준연도의 현직 관측에서 같은 학교+명부 분야 구성원 |

연구자 모드는 모든 단계에서 명부 분야(수학·물리·화학·생물)가 같은 연구자끼리 연결합니다. 분야를 알 수 없으면 연결하지 않습니다. 명부 분야는 과거 학과의 확인을 대신하지 않으며, 박사·첫 조교수 단계는 국내외 모두 과거 학과의 일치도 요구합니다. 포닥은 같은 명부 분야로 제한하되, 검증되지 않은 포닥 당시 학과를 확인된 것으로 표시하지 않습니다. 각 단계·기관·선택 연구자의 해당 구간을 하나의 집합으로 만들고, 상대 구성원마다 실제로 겹친 연도를 표시합니다. 같은 하이퍼엣지 안의 모든 구성원이 서로 같은 해에 만났다는 뜻은 아닙니다. 일반 `faculty` 분류나 논문 소속, 첫 경력 순번만으로 당시 교수 재직 또는 첫 조교수 임용을 확인했다고 표시하지 않습니다. 근거가 부족한 단계는 빈 사유를 보여줍니다.

학교 모드 및 연구자 모드의 과거 경력은 기관 국가가 불명확하면 연결하지 않습니다. 과거 학과가 필요한 관계는 학과가 없으면 만들지 않습니다. 현직 집합은 공개 기준연도에 확인된 학교와 명부 분야를 사용하므로 학과·국가 정보의 누락만으로 현직 동료를 제외하지 않습니다. 현재 재직 학과나 넓은 분야명을 박사·학부 학과로 대체하지 않습니다. 확인된 학교 별칭만 정규화하며, 해소되지 않은 숫자 기관 코드도 관계 근거로 쓰지 않습니다. 학과 문자열이 다르면 임의로 같은 학과로 합치지 않습니다.

확인된 실제 박사 구간이 있으면 우선 사용합니다. 그렇지 않으면 기본값은 `박사 취득연도 − 5`부터 취득연도까지입니다. 양 끝을 포함하므로 6개의 연도 구간이며, 실제 입학일을 뜻하지 않습니다. 선택적 학부 시간 집합은 사용자가 지정한 `박사 취득연도 − 10`부터 `− 8`까지의 3개 연도를 사용합니다. 항상 추정으로 표시하고 기본적으로 끄며, 기존 학력 날짜를 수정하지 않습니다. 추정 기간을 제외하면 두 종류의 추정 구간 모두 빠집니다.

논문 소속에서 추론한 학과는 별자리 화면에서는 기본 포함하며 선택을 바꿀 수 있습니다. 기관 인력 통계는 학과 추론을 집계 조건으로 사용하지 않습니다. 포함하면 같은 기관·기간의 채택된 저자 소속에서 하나의 명시적 학과만 확인된 경우를 사용하고, 근거에 추론 표시를 붙입니다. 해당 논문 소속은 실제 학위 수여 학과의 확인을 대신하지 않습니다. 원본에 학부 학과 근거가 없어 학부 학과는 비워 둡니다.

학교 모드 배치는 정규화 하이퍼그래프 라플라시안 기반 근사 임베딩에 집합 크기·구성원 겹침 보정, 연대 기준 배치, 노드 충돌 완화를 적용합니다. 연구자 모드는 한 사람이 속한 모든 단계의 하이퍼엣지를 함께 보존하고, 공유 구성원을 겹치는 영역에 배치합니다. 최종 화면의 거리는 측정된 사회적 거리나 전역 최적해가 아닙니다. 자세한 가중치와 계산 규칙은 [하이퍼그래프 방법](HYPERGRAPH_METHOD.md)을 참고합니다.

연구자 화면은 종합 유사도 점수 대신 단계별 집합과 구성원별 근거를 보여줍니다. 같은 학창시절 집합에 박사과정 동료와 당시 재직 교수가 함께 들어갈 수 있습니다. 단계, 겹친 연도, 재직 관측의 출처 종류, 기간·학과의 추정 여부를 함께 확인해야 합니다. 확인된 첫 조교수 구간이 있어도 같은 시기·학과의 재직 교수가 자료에 없으면 구간만 표시하고 하이퍼엣지는 만들지 않습니다.

## 학부→박사→현재기관 흐름

`#/flows`에서는 현재 재직기관·학부 출신기관·박사 출신기관을 각각 검색해 선택할 수 있습니다. 하나만 선택하면 해당 학교의 재직자 또는 출신자를 보고, 여러 조건을 선택하면 교집합을 봅니다. 분야와 학부 모교 재직 조건도 함께 적용합니다. 학교 검색은 확인된 한글명·약칭을 지원하며 표시는 영어 정식 명칭을 사용합니다.

필터는 학력 누락자를 제외하기 전에 적용합니다. 선택 분야 전체 인원, 학교 등 필터에 해당하는 인원, 세 단계 정보가 완비된 인원 및 누락 인원을 구분합니다. 흐름은 세 학교 정보가 모두 있는 연구자만 세 단계에 동일하게 포함합니다. 한 연구자는 각 단계에서 한 번, 인접한 두 단계 사이에서 각각 한 번 집계되므로 가운데 단계의 유입·유출 합이 보존됩니다. 완비율의 분모는 현재 필터에 해당하는 인원입니다.

상위 N개 학교 제한은 없습니다. 작은 학교도 개별 기관으로 표시하며 학교 수에 맞춰 그래프 높이를 계산합니다. 도표는 고정된 캔버스 영역에서 드래그·휠로 이동하고, +/− 버튼·Ctrl/⌘+휠·두 손가락 핀치로 확대·축소합니다. 기본은 가로 맞춤이며 전체 보기와 100% 보기도 제공합니다. 방향키로 이동하고 +/−로 배율 변경, 0으로 전체 보기, Home으로 가로 맞춤을 할 수 있습니다. 확대·이동은 표시 좌표만 바꾸며 인원과 흐름의 상대적 두께를 바꾸지 않습니다. 해외 교육기관의 지역 묶음은 선택 사항이며 기본적으로 끕니다. 지역 묶음을 켜도 학교 필터로 지정한 기관은 개별 표시합니다. 국가를 모르는 학교를 해외로 간주하지 않습니다. 색은 실제 학부 출신기관별로 정하며 학부 5개교 이외를 하나의 색상 범주로 합치지 않습니다.

학교·리본·개별 경로를 선택하면 해당 경로의 목록을 볼 수 있습니다. 드래그 이동은 클릭 선택과 구분하고, 화면 밖 노드에 키보드 초점이 가면 해당 라벨이 보이도록 이동합니다. 필터를 바꾸면 흐름, 인원 통계, 경로 표, 연구자 목록과 CSV를 같은 모집단에서 다시 계산하고 이전 그래프 선택과 보기 위치·배율은 초기화합니다. 단순 경로 선택은 현재 보기를 유지합니다. 실명 검색은 잠금 해제 시에만 제공하며 다시 잠그면 입력도 지웁니다.

여기서 **학부 모교 재직**은 학부 학교와 현재 재직학교가 같은 경우입니다. 박사 수여학교와 임용기관의 일치를 뜻하는 다른 자교 임용 정의와 구분해야 합니다. 학교 단위 이동을 요약하는 화면이므로 학과까지 요구하는 별자리 관계와 집계 단위가 다릅니다. 확인된 학교 별칭을 사용하고 서로 다른 캠퍼스는 보존합니다. 해소되지 않은 기관 코드는 모교 재직 판정에서 제외합니다. 집계 CSV에는 학교·인원·모교 재직 여부만 포함하며 실명이나 연구자 ID는 넣지 않습니다.

## 기관 인력 통계

`#/institutions`는 같은 학기의 실제 교수 명부에 대한 **기술통계**를 보여줍니다. 관측 인원, 전후 관측에서 달라진 소속, 박사 출신학교·국가 구성과 학위연도를 계산합니다. 학과 정보의 유무는 기관 인원 집계 조건이 아니며, 박사·포닥·교수의 추정 경력으로 명부 공백을 채우지 않습니다.

기본은 봄학기끼리의 비교입니다. 가을학기를 선택하면 가을 명부가 있는 연도만 표시합니다. 2023년은 물리학만 수집되어, 전체 분야의 2023→2024 증감·이동은 계산하지 않습니다. 유입·유출은 두 시점에 단일 기관이 관측된 사람의 소속 변경이며, 전년 미관측·이번 학기 미관측·복수 또는 미해소 기관·대학 통합 승계를 분리합니다. 신규 채용·퇴직 추정치가 아닙니다.

박사 출신 비율은 미상을 포함한 선택 명부 전체가 분모입니다. 학위 국가 미상 때문에 달라질 수 있는 해외 박사 비율의 최소·최대 범위도 표시하며, 신뢰구간으로 해석하지 않습니다. 학위연도 중앙값·사분위수는 유효한 연도가 있는 사람만 사용하고 그 인원을 따로 표시합니다.

이전 δNOA·하이퍼엣지 크기·단계 엔트로피 기반 기관 프로필은 이 페이지에서 제거했습니다. 학교·학과로 이미 정한 집합에 지표를 적용하는 것만으로 기관의 구조적 특성이 입증되지는 않으며, 현 자료에서는 관측 범위의 차이가 해석에 더 직접적인 영향을 줍니다. 개인 경력의 관계 탐색은 별자리 페이지에서 유지합니다.

집계 정의·실제 관측 범위·자료 한계는 [기관 인력 통계](INSTITUTION_STATISTICS.md), 대학 통합은 [기관 승계 처리](INSTITUTION_SUCCESSIONS.md)를 참고합니다.

## 메타데이터 갱신

기존 `public/data/dashboard.json`과 암호화 실명 번들은 보존하고, `constellation_metadata.json`과 함께 생성되는 manifest를 추가합니다. 보조 정보는 익명 ID에 맞춘 국가·학과·추론 여부·기관 정규화 근거와 경력 구간 대응, 관측된 교수 재직 및 현직 정보를 담습니다. 실명, 원본 ID, 논문 제목·ID·DOI, 검증 원문 URL은 공개하지 않습니다.

아래 명령은 저장소 루트에서 실행합니다. `PRIVATE_BUILD_PROJECT`는 기존 비공개 빌드 프로젝트의 경로를 미리 설정한 변수입니다. 해당 프로젝트의 기존 익명화 salt와 연도별 원본 DB 경로 캐시를 사용합니다. 새 salt를 생성하지 않습니다. 필요하면 `--source-db`와 `--anon-salt`로 같은 원본과 salt를 명시합니다.

```bash
python3 backend/scripts/build_constellation_metadata.py \
  --private-project "$PRIVATE_BUILD_PROJECT" \
  --public-data public/data/dashboard.json \
  --year 2026 \
  --lifetime-evidence-json "$LIFETIME_EVIDENCE_JSON" \
  --output public/data/constellation_metadata.json
```

`LIFETIME_EVIDENCE_JSON`은 비공개 공식 프로필·이력서 검토본 경로입니다. 해당 파일이 없는 재생성에서는 옵션을 생략할 수 있지만, 이전의 공식 검증 보완 행도 결과에서 빠집니다. 기존 보완을 유지하려면 같은 검토본을 제공해야 합니다. 이 파일의 실명·원본 ID·출처 URL은 공개 내보내기에서 제외합니다. 검토본은 원본 공개 파일의 해시와 인물·학위기관·취득연도에 결합해 검증합니다.

학기별 명부는 실제 관측된 연도만 교수 재직으로 추가하며, `observed_terms`에 실제로 관측한 봄·가을학기를 함께 보존합니다. 연도·학기 값이 서로 일치하는 원본 관측만 사용하고 명부 사이의 공백을 채우지 않습니다. 이력서·프로필 재직 구간에는 학기 관측을 생성하지 않습니다. 현직 관측은 마지막 관측연도를 보존하고, 연구자 모드의 현직 집합은 공개 기준연도와 일치하는 행만 사용합니다. 공식 재직 구간과 첫 조교수 직급은 별도 검토가 필요하며, 논문 소속이나 경력 순번만으로 만들지 않습니다.

연도가 바뀌면 해당 연도 공개 릴리스를 먼저 만든 뒤 `--year`도 바꿉니다. 생성기는 원본을 읽기 전용으로 열고 기존 익명 ID 집합과 연도 일치를 검사합니다. 화면은 다음 조건을 모두 만족할 때만 보조 정보를 결합합니다.

- manifest의 기준연도와 공개 JSON의 기준연도가 같다.
- 원본 공개 JSON 바이트의 SHA-256이 `public_data_sha256`과 같다.
- 보조 JSON 바이트의 SHA-256이 `metadata_sha256`과 같다.
- 익명 ID 집합과 인원 수가 같고, 각 경력 행의 순번·원래 기관·시작 및 종료 연도가 일치한다.

하나라도 맞지 않거나 보조 파일을 읽지 못하면 기존 공개 자료로 화면을 열고 보조 관계의 사용을 제한합니다. 같은 연도에 원본을 다시 만든 경우도 해시가 달라지므로 보조 파일을 함께 재생성해야 합니다. 현재 보완 범위와 누락은 생성된 manifest와 화면의 제외 집계를 기준으로 확인합니다.

## 국내 박사 학과의 2차 검증

RISS 학위논문 상세 또는 실제 학위 정보가 명시된 KISS 자료를 직접 확인한 결과는 **비공개 SQLite 검증 DB**로 분리합니다. 현재 소속이나 학술논문 저자 소속만으로 학위 학과를 확정하지 않습니다. 2026-09-08에 국내 박사 5명을 대상으로 공식 도메인 검색과 상세 접근을 시도한 제한적 파일럿에서는 확인 완료가 0명이었습니다. 접근 제한 2명, 동명이인 구분 미완료 2명, 조사 범위 안에서 일치 학위논문을 찾지 못한 경우 1명으로 기록했으며 학과를 만들어 채우지 않았습니다.

검토 기록의 전체 필드는 [검증 DB 스키마](../backend/scripts/verified_departments_schema.sql)를 따릅니다. 실제 저자·학위기관·취득연도·박사 학위·명시적 학과를 모두 확인한 행만 `verified`로 표시합니다. 그 외에는 `queued`, `access_limited`, `ambiguous_identity`, `no_matching_thesis`, `mismatch` 등 해당 상태와 확인일·출처를 기록합니다. 웹 근거 발췌는 출처별 25단어 이내로 제한합니다. 아래 변수는 저장소 밖 또는 무시되는 `.private/` 안의 비공개 파일을 가리켜야 합니다.

```bash
python3 backend/scripts/create_verified_overlay.py \
  --records-json "$DEGREE_REVIEW_JSON" \
  --output "$VERIFIED_DEPARTMENTS_DB"

python3 backend/scripts/build_constellation_metadata.py \
  --private-project "$PRIVATE_BUILD_PROJECT" \
  --public-data public/data/dashboard.json \
  --year 2026 \
  --verified-departments-db "$VERIFIED_DEPARTMENTS_DB" \
  --lifetime-evidence-json "$LIFETIME_EVIDENCE_JSON" \
  --output public/data/constellation_metadata.json
```

검증 DB 생성기는 기존 파일 덮어쓰기를 거부하므로 새 검토본으로 감사 이력을 보존합니다. 내보내기는 `verified` 행에 한해 원본 인물과 익명 ID, 기관, 취득연도, 학위 단계, 학과, 공식 상세 URL 등의 일치를 검사하며, 잘못된 확인 행이 있으면 중단합니다. 이 형식 검사는 실제 출처를 읽는 검토를 대신하지 않습니다.

검증을 통과한 학과만 `phd_department_inferred: false`와 공개 근거 `verified_degree_record`로 반영합니다. 확인된 학과가 있어도 박사과정 날짜의 기존 추정 표시는 그대로 유지합니다. 검증 DB의 실명·원본 ID·출처 URL·발췌문과 검색 대기열은 커밋하거나 공개 파일로 복사하지 않습니다. 원본 DB는 수정하지 않습니다.
