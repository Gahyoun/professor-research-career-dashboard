# RISS를 통한 국내·해외 박사학위논문 검색과 학과 검증

확인일: 2026-09-09. 국내·해외 박사학위논문 연결과 국내 박사 학과의 보강은 RISS 학위논문 후보 검색과 상세 학위기록 검토를 통해 진행한다. KRI의 대학 자체 시스템 연계 표시는 해당 대학의 내부 연구업적 시스템과의 연계를 뜻한다. 이 표시를 다른 기관 연구자의 조회 권한으로 해석하지 않으며, 현재 프로젝트의 학과 조회 경로로 사용하지 않는다.

## 이용 조건과 확인 가능한 정보

RISS 학위논문 검색 API는 이용 등록과 심사 후 발급받은 키가 필요하다. 로그인한 이용신청 화면은 승인 범위를 공익 목적 기관·단체의 도서관·자료실 홈페이지 통합검색으로 안내한다. 개인연구용 DB 구축이 승인 대상인지는 별도 확인이 필요하며, 현재 발급키는 없다. [검색 API 소개](https://www.riss.kr/apicenter/apiSearchIntro.do), [학위논문 API 명세](https://www.riss.kr/apicenter/apiSearchThesis.do), [이용 신청](https://www.riss.kr/openAPI/OpenApiRegister.do)

공식 명세에는 저자, 수여대학, 발행연도와 국내 박사(`stype=id`)·해외 박사(`stype=od`) 자료유형으로 검색하는 항목이 있다. 응답에는 제목·저자·발행처·연도·자료유형·상세 URL 등이 있지만 **학과 필드는 없다**. 초록·목차 필드도 내용이 아니라 존재 여부 표시다. 따라서 후보가 검색되어도 박사 학과 검증이 완료된 것은 아니다. 발행처가 없는 응답도 허용해야 한다. [공식 명세](https://www.riss.kr/apicenter/apiSearchThesis.do), [공식 XML 예시](https://www.riss.kr/api/xml/apiSearchThesis.xml)

요청당 결과는 최대 100건이다. 공개 명세에서 일일 호출량과 IP·Referer 제한은 확인되지 않았으므로 다른 RISS 서비스의 규칙을 가져와 적용하지 않는다. API 안내의 이용 범위 표시는 출처 표시·비영리·변경 금지이며, 수집 결과는 우선 비공개 검토에만 사용한다.

## 후보 검색과 검증의 구분

1. 기존 비공개 원본에서 이름, 박사학위 수여기관, 실제 학위연도가 확인되고 학위국가와 기관국가가 일치하는 행을 골라 검색 대기열을 만든다. 기본 범위는 국내이며 `--scope foreign` 또는 `--scope all`로 확장한다. 기존 salt와 공개 익명 ID의 전체 대응을 검증한다. 필수 정보 누락·국가 충돌은 별도로 남기고, 현재 재직 학과로 박사 학과를 채우지 않는다.
2. 발급키가 설정된 경우에만 RISS API로 저자·수여대학·학위연도를 검색 조건으로 지정해 국내 또는 해외 박사 논문 후보를 수집한다. 기관명은 원본 또는 같은 기관에 연결된 기존 별칭을 사용한다. 명세는 정확 일치·조건 결합 방식을 명시하지 않으므로 반환값을 다시 대조한다. 좁은 검색에서 결과가 없는 경우에도 논문이 없다고 확정하지 않는다.
3. 후보의 상세 학위기록에서 학과와 실제 학위 종류를 확인하고, 동명이인·기관명 변경·연도 차이를 검토한다. 이름과 연도가 같다는 것만으로 동일인으로 확정하지 않는다.
4. 사람·학위·학과 근거가 모두 확인된 기록만 기존 비공개 학위 검증 overlay에 넣는다. 공개 메타데이터 반영 시 기존 `validate_verified_record`의 사람·기관·연도·학위·학과 검사를 거친다.

API 수집 기능은 검증 overlay나 공개 메타데이터를 자동 수정하지 않는다. 결과 잘림, 인증 실패, 접근 제한, 통신 오류를 검색 결과 0건으로 바꾸지 않는다. API에 학과가 없다는 사실을 결측 학과나 현재 학과의 자동 대체 근거로 삼지 않는다.

2026년 원본에서 준비한 전체 대기열은 **211개 기관 단위, 2,264명(국내 1,596명·해외 668명)**이다. 기존 국내 54개 기관·1,596명 대기열과 동일한 국내 행을 유지한다. 원본 3,937명의 기존 익명 ID 대응과 수집기의 입력 검증을 통과했다. 원본에 적합한 한글 기관명·고유한 고신뢰 한글 별칭이 없어 검색에는 기존 영문 표준명이 유지된다. 초기 파일럿에서 RISS의 수여기관 표기와 비교해야 하며, 영문 기관명으로 검색되지 않는 경우를 논문 부재로 해석하지 않는다. 대기열 준비는 검색이나 학과 확인 완료 건수에 포함하지 않는다.

## 로컬 실행

검색 대기열과 결과는 `private` 또는 `.private` 폴더 아래에 저장한다. 파일은 0600, 전용 폴더는 0700으로 관리하며, Git 안에서는 제외 규칙에 포함되고 추적되지 않는 경로만 허용한다. 키·교수 이름·원본 ID·검색 URL을 공개 파일이나 실행 로그에 출력하지 않는다.

```bash
python3 backend/scripts/build_riss_queue.py \
  --private-project "$PRIVATE_BUILD_PROJECT" \
  --public-data public/data/dashboard.json \
  --year 2026 --scope all \
  --output "$PRIVATE_DIRECTORY/riss-query-queue.json"

# 발급받은 키를 로컬 환경변수 RISS_API_KEY에 안전하게 설정한 뒤 실행한다.
# 키 값은 명령행 인자나 저장소 파일에 넣지 않는다.
python3 backend/scripts/riss_api.py \
  --queue-json "$PRIVATE_DIRECTORY/riss-query-queue.json" \
  --output "$PRIVATE_DIRECTORY/riss-candidates.json" \
  --limit 5
```

기본 수집은 소규모 파일럿이다. 문서 예시의 키를 실행에 사용하지 않는다. 인증키가 없으면 네트워크 요청과 결과 파일 생성 전에 중단한다. 통신은 HTTPS만 사용하고 인증값이 포함된 요청의 리디렉션이나 HTTP 전환은 허용하지 않는다. HTTPS 인증 호출의 성공 여부는 발급키를 설정한 후 확인해야 한다.

확인된 학과의 반영 절차는 [별자리·흐름·기관 변화의 학위 검증](CONSTELLATIONS_AND_FLOWS.md#국내-박사-학과의-2차-검증)을 참고한다. 실명 잠금 정책과 원본 데이터는 유지한다.

수집 결과는 [학위–논문 DB](THESIS_LINKAGE.md)의 `import-riss`로 가져온다. 원본 학위와 검색 조건·실제 요청 감사 기록을 대조하며 미시도·국가 불일치·다른 사람의 검색 결과를 연결하지 않는다. DB에 들어간 RISS 결과도 상세 학위 원문을 검토하기 전까지 후보 상태다.
