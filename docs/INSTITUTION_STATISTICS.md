# 기관 인력 통계

## 분석 대상과 관측 단위

분석 대상은 공개 릴리스에 포함된 연구자 중 선택한 학기의 교수 명부에 실제로 등장한 사람입니다. 전체 국내 교수에 대한 확률표본이나 역사적 기관 인력 총조사가 아닙니다. 이 페이지는 기관별 **관측 인원·관측 소속 변경·박사 출신 구성**을 설명하는 기술통계입니다.

`faculty_appointments`의 `semester_roster`·`observed` 행에서 실제 `observed_terms`가 있는 관측만 사용합니다. 연도·학기·원본 semester 값의 대응을 생성 단계에서 검증합니다. 공식 이력서·기관 프로필 구간, 논문 소속, 추정 경력, 현직 정보의 과거 연장으로 학기를 채우지 않습니다. 학기 정보가 없는 구형 보조 파일은 학기 통계에서 제외합니다.

연구자×기관×학기는 중복 제거합니다. 전체 명부 인원은 여러 기관에 등장한 사람도 한 번만 세고, 기관별 인원은 실제로 등장한 각 기관에서 한 번씩 셉니다. 따라서 기관별 비중의 합은 100%를 넘을 수 있습니다. 학과·국가 미상은 기관 인원의 제외 사유가 아닙니다. 기관 자체를 해소하지 못한 관측도 전체 명부 분모에는 포함하되 가상의 공통 기관을 만들지 않습니다.

## 같은 학기의 비교

기본은 봄학기끼리 비교합니다. 2026년 공개 명부에는 봄학기만 있어 과거 연간 합집합과 직접 비교하면 안 됩니다. 선택한 학기의 실제 관측 연도만 표시하며, 2026년 가을을 인원 0명으로 만들지 않습니다.

| 봄학기 | 공개 릴리스 안의 관측 인원 | 수집 분야 |
| --- | ---: | --- |
| 2023 | 699 | 물리 |
| 2024 | 3,354 | 수학·물리·화학·생물 |
| 2025 | 3,213 | 수학·물리·화학·생물 |
| 2026 | 3,241 | 수학·물리·화학·생물 |

전체 분야의 2023→2024 차이는 수집 분야가 달라 비교하지 않습니다. 분야 필터로 같은 관측 범위를 선택하면 비교할 수 있습니다. 같은 분야·학기라는 조건도 기관별 수집의 완전성을 보장하지 않습니다. 명부에 없는 기관의 0은 **해당 명부에서 관측된 기록이 0건**이라는 뜻이며 실제 인력이 없다는 뜻이 아닙니다.

## 관측 소속 변경의 분해

같은 분야 범위의 인접 연도 같은 학기만 비교합니다. 전체 연구자별 기관 집합을 먼저 만든 뒤 선택 기관의 구성원을 비교하므로, 출발·도착 기관이 화면 필터 밖에 있다고 사라지지 않습니다.

| 전후 관측 | 분류 |
| --- | --- |
| 선택 기관에 두 시점 모두 등장 | 같은 기관에서 재관측 |
| 전후 단일 기관이 각각 있고 서로 다름 | 관측 소속 변경 |
| 단일 기관 전환이 시행연도 이후 지정된 대학 승계에 해당 | 통합 승계, 일반 소속 변경에서 제외 |
| 이전 학기에 어디에서도 관측되지 않음 | 전년도 미관측, 신규 채용으로 세지 않음 |
| 이번 학기에 어디에서도 관측되지 않음 | 이번 명부 미관측, 퇴직으로 세지 않음 |
| 어느 한쪽 기관이 복수이거나 미해소 | 이동 판정 보류 |
| 전년도 같은 학기가 없거나 수집 분야가 다름 | 비교 불가, 수치 미정 |

각 기관의 새 관측 인원은 `관측 유입 + 승계 유입 + 전년 미관측 + 판정 보류`로, 명부에서 빠진 인원은 대응하는 유출 항목으로 분해됩니다. `이전 인원 + 새 관측 − 명부 이탈 = 이번 인원`을 검사합니다. 단순 인원 차이는 유입−유출과 다를 수 있으며 고용 순증이 아닙니다. 출발·도착 기관 비율은 통합을 제외한 단일 기관 간 관측 소속 변경 인원이 분모입니다.

학교 병합의 시행일·별칭은 [기관 승계 처리](INSTITUTION_SUCCESSIONS.md)를 따릅니다. 표시명과 집계 ID를 분리해 강원대·경상대의 집계 ID를 통합 전후 유지하고, 강릉원주대·경남과기대는 시행연도부터 승계 ID에 합칩니다. 통합 전 영어·한국어 별칭도 같은 ID로 정규화합니다. 기존 강원대 계속 관측자를 이름 변경만으로 승계 유입에 넣지 않습니다. 원본 경력·학위 기관명은 보존합니다.

현재 공개 명부의 독립 검산에서 2024→2025 봄학기 단일 기관 변경은 50명, 2025→2026은 19명입니다. 2026년 통합 승계는 16명이며 기존 강원대의 계속 관측 63명은 재관측으로 남습니다. 이는 양 학기에 관측된 부분집합의 소속 변경이며 전체 이직 건수 추정치가 아닙니다.

## 박사 출신 구성과 누락

선택 기관·학기·분야의 전체 관측 인원 N이 출신학교·국가 비율의 공통 분모입니다. 학교·국가 미상을 별도 항목으로 남깁니다. 박사 수여학교는 역사적 학위기관을 사용하고 현재 통합 기관명으로 바꾸지 않습니다. 학교 문자열로 국가를 추측하지 않습니다.

국외 박사 F명, 국가 미상 U명일 때 가능한 국외 비중 범위는 `F/N`부터 `(F+U)/N`입니다. 이는 알려진 국가 분류가 맞다는 조건에서 미상을 전부 국내/국외로 놓은 **누락 자료의 범위**이며 확률적 신뢰구간이 아닙니다. N=0이면 비중을 계산하지 않습니다.

학위연도 중앙값과 1·3사분위수는 관측 학기 연도 이하의 유효한 정수 학위연도만 사용하고, 그 인원과 미상·무효 인원을 표시합니다. 오름차순 값 x에서 위치 `(n−1)p`를 선형 보간하는 경험적 분위수입니다. 학위연도는 나이·근속기간을 뜻하지 않습니다.

## 통계적 해석의 범위

관측값의 분모와 누락을 먼저 고정하며 자동 p값·모집단 순위·bootstrap 신뢰구간을 붙이지 않습니다. 현재 자료의 지배적인 불확실성은 연구자 반복 관측과 수집·선택·누락 구조입니다. 단순 재표집으로 그 편향이 해결되지는 않습니다. 비확률 자료와 표본오차의 관계는 [Statistics Canada: Non-probability sampling](https://www150.statcan.gc.ca/n1/edu/power-pouvoir/ch13/nonprob/5214898-eng.htm), 표본오차와 비표본오차의 구분은 [Questions to ask about surveys](https://www.statcan.gc.ca/en/customized-products-services/custom-surveys/questions-to-ask)를 참고합니다.

추후 기관 간 차이를 검정하려면 비교할 모집단·동일 수집 범위·분야와 학위연도 구성·결측 처리·연구자 반복 관측을 반영한 추정 대상을 먼저 정해야 합니다. 이전 기관 프로필의 δNOA와 하이퍼그래프 방법 비교는 이 페이지의 분석 근거로 사용하지 않습니다. 개인 관계 탐색용 경력 하이퍼그래프는 별도 페이지에 유지합니다.
