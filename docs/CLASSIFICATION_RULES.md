# 경력·기관·논문 분류 기준

이 문서는 2026 공개 릴리스의 결정 규칙을 고정한다. 자동 추론은 증거보다 강하지 않으며, 확정·고신뢰·추정 상태를 데이터에 함께 저장한다.

## 1. 학력과 경력 단계

### 학부

- 학부 기관명이 있으면 교수 요약 항목에만 표시한다.
- 재학기간은 군복무·휴학·편입 등의 변수가 크므로 타임라인에 넣지 않는다.

### 박사과정

- 박사학위 수여연도만 확정된 경우 `수여연도 - 5`년 상반기부터 수여연도 하반기까지를 추정 박사과정으로 둔다.
- 이 구간은 `estimated`로 저장하고 화면에서는 수여연도에 가까울수록 진해지는 빨강 그라데이션으로 표시한다.
- 실제 입학연도 증거가 추가되면 추정값보다 실제 값을 우선한다.
- 박사학위 연도를 아는 연구자의 `학위연도 - 5`보다 이른 논문·소속은 동명이인 시간 오류로 강제 분류한다. 원본을 삭제하지 않고 `duplicate_drop_candidate`에 격리하며 경력·생산성에서는 제외한다.
- 경력 구간이 이 경계를 가로지르면 시작점을 `학위연도 - 5`년 상반기로 절단한다. 경계보다 완전히 이른 파생 경력·소속 구간은 조회용 캐시에서 제거하되, 근거 논문과 원문 소속은 격리 테이블에 보존한다.
- 이 시간 게이트는 분야 유사도·ORCID 일치보다 우선한다. 동일한 이름이나 ORCID가 붙어 있어도 연구자가 정상적으로 박사과정을 시작하기 전인 자료는 자동 집계하지 않는다.

### 포닥·연구원

- 박사 이후 교수 임용 전의 대학·연구소 소속을 기관별로 분리한다. 서로 기간이 겹치는 복수 소속도 허용한다.
- 박사기관과 같은 곳에서 포닥한 경우에는 학위수여 뒤 해당 기관 주소가 붙은 논문이 실제로 존재하고, 첫 교수직 이전인 때만 별도 포닥 구간을 만든다.
- 직함 원문이 `Research Professor`, `Research Prof.` 또는 `연구교수`이면 교수직이 아니라 포닥·연구원으로 분류한다.
- 연구교수 증거가 있는 기관에 자동 생성된 교수 구간은 제거하고, 직함이 확인된 반기만 확정 연구 구간으로 남긴다.

### 교수직과 이동

- 원본 경력 DB의 교수직을 우선 사용한다.
- 보조 추론은 국내 교육기관의 학과·학부 소속 논문이 2개 반기 이상 있고, 포닥과 겹치지 않으며, 현재 교수직 시작과 1년 이내로 이어지는 경우에만 이전 교수기관 후보로 인정한다.
- 학과명만으로 역할을 확정하지 않는다. 연구교수 표기는 항상 위 포닥 규칙이 우선한다.
- 첫·두 번째 교수직은 시간순으로 번호를 부여하며, 현재 재직기관은 최신 명부의 정규화 기관명을 사용한다.

## 2. 기관명과 캠퍼스

- 화면과 공개 DB에는 약칭 대신 OpenAlex/ROR 또는 명시적 별칭 사전의 풀네임을 쓴다.
- 같은 기관의 우편번호가 가깝고 같은 캠퍼스 안 대학·연구소를 함께 표시한 경우에는 중복으로 버리지 않고 복수 소속으로 보존한다.
- 우편번호·도시가 크게 다른 본교와 분교는 별도 기관으로 취급한다. 현재 명부의 명시적 캠퍼스 표기를 최우선으로 사용한다.
  - `Korea University (Seoul Campus)` / `Korea University (Sejong Campus)`
  - `Yonsei University (Seoul Campus)` / `Yonsei University (Mirae Campus)`
  - `Hanyang University (Seoul Campus)` / `Hanyang University (ERICA Campus)`
- 연세대학교 송도 국제캠퍼스는 신입생 공통 교육 장소만으로 별도 재직기관을 만들지 않는다.
- 기관 통합·개명은 역사 구간과 현재 구간을 나눈다. 국립안동대학교 소속은 2024년까지 `Andong National University`, 2025년 상반기부터 `Gyeongguk National University (Andong Campus)`로 저장하며 기관 승계 플래그를 켠다.

## 3. OpenAlex 동명이인과 다중 저자 ID

- 2026 웹 릴리스는 KOAD 1.0의 박사기관·학과 적합 데뷔 seed와 핵심 공저자, 기관, 주제 의미 계열, 검증 논문군 graph 경로를 사용한다.
- `keep`·`drop` 자동판정만 웹 DB에 반영하고, `review`는 직전 판단을 유지한다. 따라서 검토 대기 논문이 재빌드만으로 갑자기 노출되거나 사라지지 않는다.
- ORCID 단독 일치는 보존 근거가 아니다. 잘못 합쳐진 OpenAlex 저자 레코드에서 ORCID가 전파될 수 있으므로 다른 연결 증거가 필요하다.
- 적용 전후 판단과 원인 코드는 비공개 웹 빌드 DB의 `koad_application_audit`에 보존한다. 제외 논문은 반기 소속 캐시의 source work ID에서도 제거한다.
- 원본 저자소속 연속성·주요 연구 분야·기관 경력을 함께 사용해 `keep` 판정된 논문만 공개 집계한다.
- 주 연구 도메인과 멀고 전후 반기 기관 연속성도 없는 논문은 `duplicate_drop_candidate`로 격리하며 생산성에서 제외한다.
- 이산수학–네트워크과학, 생태계 동역학 모델링–수리생물학처럼 방법·대상이 이어지는 인접 분야는 유지한다. 네트워크과학–건축학처럼 연구주제·기관경력 양쪽이 끊기는 조합은 오류 후보로 본다.
- 한 교수에게 수동 표시된 복수 OpenAlex 저자 ID는 하나의 공개 교수 ID로 합친다. 같은 논문이 두 저자 ID에 잡혀도 OpenAlex work ID 기준 한 번만 센다.
- 분야 거리만으로 자동 삭제하지 않는다. 분야 거리, 기관 연속성, 공저자 연속성, 논문 시점의 네 증거를 결합하고, 경계 사례는 격리 후 검토한다.
- 단, 박사학위 연도가 확인된 경우 `학위연도 - 5` 이전이라는 시간 모순은 단독으로도 강제 격리하는 하드 게이트다.

## 4. 논문과 저널 지표

- 주저자 논문은 OpenAlex에서 `author_position=first` 또는 `is_corresponding=true`인 논문이다.
- article, review, letter, editorial 중 동명이인 필터를 통과한 논문만 센다.
- 저널 지표는 Clarivate JIF가 아니라 공개 재현 가능한 OpenAlex `2yr_mean_citedness`다.
- 기본 구간은 낮음 `<2`, 중간 `2–5`, 높음 `≥5`, 지표 없음으로 나눈다.
- 연도별 자료는 연구자의 실제 최소연도부터 릴리스 연도까지 빠진 해를 0으로 채운다. 그룹 비교는 선택된 교수들의 공통 실제 최소–최대 연도축을 사용한다.

## 5. 품질검사와 한계

- 공개 JSON·SQLite에는 평문 실명, 원본 교수 ID, OpenAlex 저자 ID, ORCID, DOI, 논문 제목을 넣지 않는다.
- 매 빌드에서 SQLite 무결성, 외래키, 익명 ID 유일성, 연도축 연속성, 캠퍼스 미구분 현재기관, 구 교명 잔존 여부를 검사한다.
- 익명 표본의 한양대학교→부산대학교 이동, 통계물리 표본의 포닥·교수 경력, 연구교수의 포닥 분류, 국립경국대학교 승계를 회귀검사로 고정한다.
- 논문 소속만으로 고용형태를 완전히 증명할 수는 없다. `estimated`·`high` 결과는 공개 출처나 이력서 증거가 들어오면 갱신한다.
