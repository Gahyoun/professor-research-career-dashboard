# 학력·임용 흐름의 학교 대표색

흰색·회색조 화면 안에서 다음 다섯 대학의 기관 막대는 학사·박사·현재 재직 단계에 걸쳐 같은 대표색을 사용한다. 연결 흐름과 경로 표의 색상은 기존처럼 학부 출신기관을 기준으로 유지한다.

| 대학 | 화면 색상 | 확인 근거 |

| 서울대학교 | `#0F0F70` · RGB 15, 15, 112 | [공식 SNU Blue 색상표](https://identity.snu.ac.kr/webdata/uploads/identity/image/2021/06/3-1-2-all.png) |
| 고려대학교 | `#872434` · RGB 135, 36, 52 | [공식 Crimson 색상 견본](https://www.korea.ac.kr/sites/en/images/contents/symbol_7.png), [교색 안내](https://www.korea.ac.kr/en/1016/subview.do) |

2026-11-02 확인. KAIST 값은 공식 이미지에서 추출한 표시용 색상이며, 학교가 별도로 명시한 RGB 표준값으로 해석하지 않는다.

국·영문 별칭과 내부 기관 키를 같은 색상으로 표시한다. 연세대 미래캠퍼스와 고려대 세종캠퍼스는 본교와 대표색을 공유하지만, 기관 키·집계·모교 재직 판정은 계속 구분한다. 부속병원이나 이름이 비슷한 다른 기관은 색상 대상으로 포함하지 않는다.

이 외 학부 출신기관은 기존의 기관별 고정 해시 색상을 유지한다. 비대상 박사·현재기관의 막대 색상과 미확인 기관의 학부 색상도 기존 기준을 유지한다.
