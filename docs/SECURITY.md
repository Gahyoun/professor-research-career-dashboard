# Privacy and security

- 공개 JSON과 SQLite에는 평문 실명, 원본 교수 ID, ORCID, DOI, 논문 제목을 넣지 않는다.
- 익명 ID는 로컬 비밀 salt를 사용한 HMAC-SHA256으로 생성한다.
- 실명 매핑은 PBKDF2-SHA256(600,000회)과 AES-256-GCM으로 암호화한다.
- 비밀번호와 OpenAlex API 키는 환경변수로만 전달하며 저장소에 기록하지 않는다.
- GitHub Pages는 정적 호스팅이므로 비밀번호 검증은 서버 인증이 아니다. 공격자는 암호화 파일을 내려받아 오프라인 추측을 시도할 수 있으므로 긴 비밀번호가 필요하다.
- 잠금 해제 전에는 익명 ID로 별자리·흐름·기관 변화와 해당 구성원 목록을 탐색할 수 있다. 기존 실명 기반 그룹 쿼리 UI는 잠금 해제 후 활성화한다.
- `.private/anon_salt.bin`을 안전하게 백업해야 2027년에도 익명 ID가 유지된다.

## 새 탐색 화면의 경계

- 복호화한 이름은 메인 화면의 메모리에만 두고 표시할 때 익명 ID에 대응시킨다. 비밀번호·실명 매핑을 브라우저 저장소, URL, Web Worker 입력, 집계 CSV에 넣지 않는다.
- 잠금을 다시 걸면 실명 매핑을 지우고 익명 표기로 되돌린다. 진행 중이던 잠금 해제 요청은 세대 번호로 무효화해 늦게 끝난 복호화가 다시 실명을 표시하지 못하게 한다.
- 그래프 입력은 공개에 필요한 필드만 명시적으로 복사한다. 원본 객체를 그대로 Worker에 보내거나 복호화된 이름을 그래프 상태에 섞지 않는다.
- 보조 메타데이터는 기준연도, 공개 JSON과 보조 JSON 각각의 SHA-256, 익명 ID 전체 집합, 경력 행의 기관·기간 대응을 모두 검증한 뒤 결합한다. 불일치하면 기존 공개 자료로 열고 해당 보조 정보를 사용하지 않는다. 해시는 버전 대응 검사이며 별도의 접근 인증이 아니다.
- RISS/KISS 검증 DB와 검색 대기열은 비공개로 보관한다. 공개 메타데이터에는 확인된 학과와 `verified_degree_record` 같은 근거 종류만 남기고 실명·원본 ID·원문 URL·발췌문을 내보내지 않는다. 원본 DB를 수정하지 않는다.
- 익명 ID가 있어도 기관·분야·학위연도·경력 조합으로 외부 공개 자료와 대조할 가능성은 남는다. 이 화면의 익명 표시는 재식별 불가능성이나 공개 JSON·다운로드에 대한 접근통제를 보장하지 않는다.
