# Privacy and security

- 공개 JSON과 SQLite에는 평문 실명, 원본 교수 ID, ORCID, DOI, 논문 제목을 넣지 않는다.
- 익명 ID는 로컬 비밀 salt를 사용한 HMAC-SHA256으로 생성한다.
- 실명 매핑은 PBKDF2-SHA256(600,000회)과 AES-256-GCM으로 암호화한다.
- 비밀번호와 OpenAlex API 키는 환경변수로만 전달하며 저장소에 기록하지 않는다.
- GitHub Pages는 정적 호스팅이므로 비밀번호 검증은 서버 인증이 아니다. 공격자는 암호화 파일을 내려받아 오프라인 추측을 시도할 수 있으므로 긴 비밀번호가 필요하다.
- 잠금 해제 전에는 실명뿐 아니라 실명 기반 교수 목록을 반환하는 그룹 쿼리 UI도 비활성화한다. 다만 공개 통계 자체는 익명 데이터이므로 다운로드와 역공학을 막는 접근통제 수단은 아니다.
- `.private/anon_salt.bin`을 안전하게 백업해야 2027년에도 익명 ID가 유지된다.
